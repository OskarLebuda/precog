# nuxt-precog

> Renamed to [`@precog/nuxt`](https://www.npmjs.com/package/@precog/nuxt).

This package forwards to it, so an existing install keeps working. New projects should use the
new name, which lives alongside [`@precog/next`](https://www.npmjs.com/package/@precog/next) in
one workspace.

```sh
npx nuxt module remove nuxt-precog
npx nuxt module add @precog/nuxt
```

Documentation: <https://precog.oskarlebuda.dev>
