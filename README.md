# nuxt-precog

> Your links, loaded before the click.

A Nuxt module that asks [TypeSafe](https://typesafe.ai/) Jev which link a visitor is about
to click, then warms exactly that navigation with the
[Speculation Rules API](https://developer.mozilla.org/en-US/docs/Web/API/Speculation_Rules_API)
and Nuxt's own route preloading.

Work in progress. See `AGENTS.md` for the current status.
