# Releasing

> How a version of this package reaches npm, and why no token is involved.

## Trusted publishing

Releases go out from GitHub Actions with [npm trusted publishing](https://docs.npmjs.com/trusted-publishers).
There is no `NPM_TOKEN` in the repository secrets and no publish token anywhere. The workflow
asks GitHub for a short-lived OIDC token, npm verifies it came from this repository and this
workflow file, and publishes. Provenance is attached automatically.

What makes it work:

| Piece                          | Where                                                                         |
| ------------------------------ | ----------------------------------------------------------------------------- |
| `permissions: id-token: write` | `.github/workflows/release.yml`                                               |
| npm 11.5.1 or newer            | installed in the workflow, on Node 24                                         |
| `npm publish` with no token    | the last step of the workflow                                                 |
| Trusted publisher config       | npm package settings, pointing at `OskarLebuda/nuxt-precog` and `release.yml` |

## Cutting a release

```sh
pnpm release
```

That runs the checks, builds the module and the DevTools client, writes the changelog, bumps
the version, tags it and pushes. The tag starts the workflow, which publishes.

## The one time a token is needed

::warning
A trusted publisher can only be configured on a package that already exists, because the
setting lives on the package's own settings page on npm. A brand new name has to be published
once by a human first.
::

For the very first release:

```sh
npm login              # browser flow, no long-lived token stored in CI
pnpm build
npm publish --ignore-scripts
```

Then, on `https://www.npmjs.com/package/nuxt-precog/access`, add a trusted publisher:

- Organisation or user: `OskarLebuda`
- Repository: `nuxt-precog`
- Workflow filename: `release.yml`
- Environment: leave empty

From then on every release is tokenless.
